# Business Card Generator

A responsive digital business-card generator developed as a frontend technical assessment.

## Project goal

Reproduce a provided interface and interaction flow while demonstrating form validation, responsive design, semantic HTML, accessibility and SEO practices.

## Features

- Validated name, email and phone fields
- Responsive form and generated-card views
- Input masking and schema validation
- Accessible and semantic interface

## Technologies

- **TypeScript**
- **React**
- **Next.js**
- **Tailwind CSS**
- **React Hook Form**
- **Zod**

## What I learned

- Turning a design specification into reusable React components
- Combining schema validation with form state
- Balancing scope and delivery under a two-day deadline
- Improving accessibility, semantics and responsive behavior

## Running locally

```bash
npm install
npm run dev
```

## About this repository

This repository documents a learning project and the technical decisions explored while building it. It is not presented as a production-ready system.
